FRC-style command-based programming for VEX V5 in Java, running on the brain through Hydrozoa. Class and method names follow WPILib, so FRC code reads the same.

Where to start

  • {@link com.robojacks.lib.robot.VexRobot} is the robot's lifecycle (like {@code TimedRobot}).
  • {@link com.robojacks.lib.command.SubsystemBase}, {@link com.robojacks.lib.command.Command}, {@link com.robojacks.lib.command.Commands} and {@link com.robojacks.lib.command.Trigger} are command-based programming.
  • {@link com.robojacks.lib.input.VexController} is the V5 controller.
  • {@link com.robojacks.lib.hardware.VexMotor} and {@link com.robojacks.lib.hardware.VexMotorConfig} drive motors; the rest of {@code com.robojacks.lib.hardware} covers sensors, 3-wire devices, pneumatics and the brain screen.
  • {@link com.robojacks.lib.estimator.DifferentialDrivePoseEstimator} and {@link com.robojacks.lib.vision.GpsPoseEstimator} track where the robot is.
  • {@link com.robojacks.lib.auto.AutoBuilder} and {@link com.robojacks.lib.auto.AutoSelector} build and choose autonomous routines.

The guides, path planner and dashboard are on the main site. The template robot and the Clawbot example are documented here too, under their own groups.
