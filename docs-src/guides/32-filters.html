Four small classes, with WPILib's names, for taming signals: limit how fast a value changes, ignore blips, smooth noise, and reject glitches.

ClassUse it to
SlewRateLimiterLimit acceleration from the sticks so the robot doesn't tip or spin its wheels
DebouncerIgnore on/off changes that don't last (bouncing switches, flickering sensors)
LinearFilterSmooth a noisy number (moving average, exponential smoothing)
MedianFilterReject single wild readings

All of them keep state, so create one per signal as a field, and call it once per loop.

SlewRateLimiter

Limits how fast a value can change, in units per second. On stick input, it turns a slammed stick into a quick but controlled ramp:

{{SNIP:examples/docs/src/main/java/com/robojacks/docs/ExampleDriverAssist.java#slew}}

A rate of 1/0.3 means full speed (1.0) takes at least 0.3 s. Use two different rates (new SlewRateLimiter(up, down, initial)) to accelerate gently but stop quickly. Reset it in initialize() so a new command starts from zero.

Debouncer

private final Debouncer m_pieceDebouncer = new Debouncer(0.1, Debouncer.DebounceType.kBoth);

boolean hasPiece = m_pieceDebouncer.calculate(m_distance.isWithin(0.05));

kRising (the default) delays only false→true, kFalling only true→false, kBoth both. For triggers, trigger.debounce(seconds) does this for you (Controllers & triggers).

LinearFilter

private final LinearFilter m_currentFilter = LinearFilter.movingAverage(10);  // last 10 readings
private final LinearFilter m_smooth = LinearFilter.singlePoleIIR(0.1, 0.010); // 0.1 s time constant

double amps = m_currentFilter.calculate(m_motor.getOutputCurrent());

Smoothing adds delay: a 10-sample moving average at 10 ms lags by about 50 ms. Use the smallest amount that does the job. A typical use is detecting a stall: when the filtered current stays high and the velocity is near zero, the claw has closed on something.

MedianFilter

private final MedianFilter m_distanceFilter = new MedianFilter(5);

double d = m_distanceFilter.calculate(m_distance.getDistanceMeters());

The median of the last few readings. One glitch (a reflection, a sensor hiccup) doesn't move it at all, where it would drag an average.
